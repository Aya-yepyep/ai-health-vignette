# 生成式AI健康信息与判断研究：预测试新稿

这是经研究者授权重新编写的中文情景预测试网站，不是遗失原问卷的复原件。具体题目尚未完成信效度检验。

当前版本为 `pilot-2026-11-02-v3`。包含28个必答字段（25项精简问题和3次模拟情景选择）及9个随机条件（3种解释/验证线索版本×3种区组顺序）。情景分为了解处境、比较资料、模拟追问、最后安排四步。对话由研究者预先编写，不实时调用AI。题目编码、三题均值和解释边界见 [编码表](research/PILOT_CODEBOOK.md)。v3移除了反向题。

完成提交后，网页提供当前情景中的五类ERT探索性人机协作反馈，并结合JD、EC、EA作辅助解释。这不是经过验证的人格分类或稳定类型诊断：目前没有有效的分类阈值，分数接近、并列或整体较低时应解释为混合倾向或类型不明显，不能强行归类。

GitHub Pages应选择 `main` 分支的 `/(root)`。此仓库只放网站和研究工具源码，不存放受访者数据。

网页调用Supabase Edge Function；浏览器只含可公开的publishable key。服务密钥由Supabase运行环境提供，数据库表不允许匿名或普通登录用户直接读取、修改或删除。后端只提供开始会话和提交接口。公开密钥并非防机器人机制；当前未配置验证码或跨会话自然人去重。

新版只创建 `pilot-2026-11-02-v3` 会话。[v1归档](research/archive/v1/manifest.json)与[v2归档](research/archive/v2/manifest.json)保留相应问卷配置、服务端研究定义及编码表。旧版停止创建新会话，仅允许已取得、仍未过期的既有会话令牌续填。网页会在当前标签页发现合法的旧版未提交草稿时继续上一版；旧版配置载入失败时保留草稿并提示刷新，不会自动切换新版。浏览器禁止读取草稿时，参与者可明确选择仅在当前页面内填写；该选项不会清除旧草稿。

网站使用由 `build_bundle.py` 生成的单个经典脚本 `questionnaire.js`，减少模块逐个加载失败造成的空白。HTML保留静态载入说明和重新载入入口；配置请求限时，失败后显示重试按钮。这些兼容性改进不等于已查明任何特定设备之前出现空白的原因。

情景与反馈说明已经变更，研究记录必须按 `version` 分开分析；不得把新旧版本不加区分地合并。源码JSON中的active=false是安全的注册默认值，实际启停和旧版续填限制由研究者在Supabase后台管理。`schema.sql`是已应用建表语句的源码备份，不可在已部署项目重复运行。

研究者可从Supabase后台导出答卷，再用 `tools/export_csv.py` 离线展开每题一列；默认剔除is_test=true的技术测试数据。不要把任何原始导出或答卷提交到本仓库。

网站、数据库部署、公开网址验证分别记录；仅有仓库文件不表示Pages已经上线。
